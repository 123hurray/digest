X 射线天空中的"隐形人"：为什么有些宇宙爆发现象"暗"得离谱

背景：先有"暗伽马暴"，再有"暗 X 射线暂现源"

天文学里有个词叫"暗暴"（dark burst）。故事要从伽马射线暴（GRB）说起：这类宇宙中最剧烈的爆炸，按理说爆发后应该能在可见光波段看到余辉，但有一些却怎么也找不到光学对应体，它们就是"暗伽马暴"。后来的研究发现，很多暗伽马暴其实是被宿主星系里的大量尘埃挡住了：光被尘埃吸收了，所以显得"暗"。

这几年，中国的"爱因斯坦探针"卫星（Einstein Probe）在天上发现了一批新的爆发现象，快速 X 射线暂现源（Fast X-ray Transient，简称 FXT）。它们在 X 射线波段突然亮起，又在几小时到几天内暗下去，其中一些同样找不到光学对应体，被称为"暗 FXT"。很自然的问题是：暗 FXT 是不是也像暗伽马暴一样，只是被尘埃挡住了？

研究人员做了什么

这篇论文的第一作者 Javier Sánchez-Sierras（荷兰拉德堡德大学）带领的团队指出：不能直接照搬伽马暴的解释，因为 X 射线和伽马射线的"穿透力"不一样。软 X 射线（能量较低的 X 射线）很容易被星际气体吸收，而伽马射线几乎不受影响。

他们的推理链条是这样的：爱因斯坦探针的宽视场 X 射线望远镜（EP-WXT）工作在软 X 射线波段。一个被气体包裹的暗 FXT 要想被 EP-WXT 看到，它发出的 X 射线在"静止系"（也就是它自己所在处的）能量必须高于 2–3 keV，这样即使被气体吸收掉一部分，剩下的还能被我们捕捉到。而宇宙膨胀会把光子的能量"拉低"（红移效应：红移 z 越大，我们看到的能量越低）。所以，要让静止系 2–3 keV 的光子落进 EP-WXT 的探测窗口，这个源的红移必须 z ≳ 2，也就是它至少来自宇宙年龄不到 33 亿年时的远古宇宙。

为了验证这个想法，团队具体分析了两个暗 FXT。EP241103a 在光学波段完全没看到对应体，研究认为它的宿主星系消光（尘埃遮挡）非常严重；按可能的红移约 2.5 来算，它发出的 X 射线受气体吸收的影响并不大。EP260409a 光学同样没看到，但在近红外波段找到了对应体，这本身就是一个"高红移"的信号（远古天体的光会被红移到红外波段），团队认为它很可能位于 z ≳ 4。

团队还做了模拟：对于被浓密气体包裹的爆发（气体柱密度 NH ≳ 10²² cm⁻²，可以理解为视线方向上的气体有多"厚"），在低红移处 EP-WXT 反而很难探测到它们，因为低红移时，严重的吸收会直接把信号"吃掉"。

发现了什么：暗 FXT 天然偏向远古宇宙

爱因斯坦探针看到的暗 FXT，很可能本来就来自中等到高红移的远古宇宙，这是一种"选择效应"——不是它们不存在于近处，而是近处的暗 FXT 会被气体吸收挡得严严实实，根本进不了我们的样本。这和暗伽马暴的情况不一样：暗伽马暴的"暗"主要归因于尘埃，而暗 FXT 的"暗"更多是气体吸收加上红移共同作用的结果。

为什么重要

这项工作帮天文学家理清了一个容易混淆的概念：同样是"看不到光学对应体"，背后的物理可以完全不同。它也给未来的观测指了路。想搞清楚暗 FXT 的真面目（它们到底是远古的伽马暴，还是某种全新的爆发现象），近红外后续观测比光学观测更关键，因为它们大概率就藏在宇宙深处。
